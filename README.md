# Final Project - Emotion Detection

A web application built with Python and Flask that utilizes Watson NLP to analyze text and detect underlying emotions.

## 🚀 Features
* **Emotion Analysis:** Processes text inputs to identify various emotions.
* **Web Interface:** Integrated with Flask to provide a seamless web-based user experience.
* **Modular Code Structure:** Cleanly organized Python packages and modules for maintainability.

## 🛠️ Technologies Used
* **Python**
* **Flask**
* **Watson NLP / AI Libraries**
